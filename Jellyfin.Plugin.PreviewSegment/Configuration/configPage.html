Preview Segment

This plugin adds a Preview media segment (from the start of the episode to the beginning of the intro) for every episode that already has an Intro segment (e.g. from the Intro Skipper plugin).

Select the libraries that should receive Preview segments below, then run Dashboard → Scheduled Tasks → Extract Media Segments (or wait for its scheduled run).

Note: use this list, not the per-library “Media Segment Providers” checkboxes — that native toggle is ineffective on Jellyfin 10.11. Leaving every library unchecked disables the plugin entirely.
