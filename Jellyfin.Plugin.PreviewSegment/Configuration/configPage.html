Preview Segment

This plugin adds a Preview media segment (from the start of the episode to the beginning of the intro) for every episode that already has an Intro segment.

There is nothing to configure here. It works as a media segment provider:

  1. Make sure your episodes already have Intro segments (for example via the Intro Skipper plugin).
  2. Enable the Preview Segment provider for the relevant libraries under Dashboard → Libraries → (your library) → Media Segment Providers.
  3. Run Dashboard → Scheduled Tasks → Extract Media Segments (or wait for its scheduled run). Preview segments are then created and shown by clients.
